# CAM93 Mobile

Application Android du Club Athlétique de Montreuil 93.

L'application propose un accueil mobile et des raccourcis vers le site officiel https://cam93.org/ : actualités, disciplines, résultats, records, installations et inscriptions.

## Générer l'APK

Chaque push sur `main` déclenche GitHub Actions. Une fois le workflow terminé, téléchargez l'artefact **CAM93-Mobile-debug-apk** depuis l'onglet Actions.

L'application utilise les contenus et services du site officiel du club. Elle n'est pas une application officielle publiée ou garantie par le club.
